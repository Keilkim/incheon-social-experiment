## 3. 실무 절차·체크리스트·판단 기준의 4편 배정

초안 위치는 A쪽 기준이다. 버전 전용 쪽은 해당 권의 쪽을 적었다.

### PART 01 기획하기

**사회문제 진단**
- **A5:** 제안을 '문제·장소·당사자·희망 변화' 4문장으로 정리한다. 제안만으로 설치·행사를 확정하지 않는다. 근거는 sd p55 시민디자인단 아이디어·민원.
- **B5:** 공공 문제 → 불확실성 → 실험 질문 → 사업 범위. 이미 정해진 공사를 실험이라 부르지 않는다.
- **H5:** 실험 제안·단순 문의·기존 사업 요청으로 경로를 구분한다. 담당 미정 제안은 처리 완료로 표시하지 않는다.
- **A11:** 출처·기준연도·공간 범위·집계 단위를 기록한다. 시 전체 통계를 특정 골목에 옮기지 않는다. 근거는 sd p41 당위성 조사, 소상공인 365.
- **A12:** 위치번호·도구·기준점·반복값을 남긴다. 육안 추정치를 실측값으로 쓰지 않는다.
- **A13:** 1건의 정의를 먼저 합의한다. 고유 인원을 가리지 못했으면 '통행 횟수'로 보고한다. 근거는 sd p126 현장조사 '평일·주말·낮·밤'.
- **A14:** 최근의 구체 장면을 묻고 비이용자도 포함한다. 한 사람 의견을 집단 요구로 단정하지 않는다. 근거는 sd p49–50.
- **A17:** 관찰 사실 → 해석 → 검증 질문. 계획서의 예상 효과를 조사 결과로 쓰지 않는다.
- **A19:** 누가·어디서·언제·무엇이 어려운가 + 근거 ID. 해결안 이름을 문제로 쓰지 않는다. 근거는 sd p56.

**거점 선정 기준**
- **A16:** 문제 근거·사용 조건·관리 부담을 같은 항목으로 비교한다. 가중치는 먼저 정하고, 필수 조건 공백을 높은 점수로 덮지 않는다. 탈락 사유도 기록한다.
  - 인천 근거: sd p42 선정 기준 6개(시민 접근성·가시성·안전성·활용성·상징성·사회실험 파급력)와 조사 3종(정책 여건·계획/선행연구·지역 조건)
- **A10:** 확보·협의 중·미확인 3상태로 표시한다. 필수 조건 미확인은 총점으로 상쇄하지 않는다.
- **B18:** 장소 ID를 기획서·도면·측정자료에 같은 이름으로 쓴다(이 한 줄만 살림).

**가설 설정 방법**
- **A21:** 개입·대상·조건·예상 변화를 각각 적는다. 산출 / 단기 변화 / 장기 기대를 구분한다. 설치·참여 건수만으로 해결을 판정하지 않는다. 근거는 sd p44 측정 원칙 6개와 거점별 가설(sd p59–123).

- **A8:** 실행·결정·검토·지원 담당을 구분하고 4주체×4단계 매트릭스로 정리한다. 근거는 sd p53 거버넌스.
