## 2. 절대 금지
- 표 + 두 문단 반복 지면. 표는 정말 표가 필요한 곳(과업 이행 대조, 출처 일람 등)에만. 반복되는 내용은 다이어그램/인포그래픽으로.
- 보고서를 설명하는 메타 문장("본 보고서는/이 장에서는 ~정리한다·구분한다·설명한다", "~로 단정하지 않는다", "원본 확인 후 채운다", "실험 후 작성 예정").
- 근거코드·편집기준·기준일·"원본 미열람"·"사용자 확인" 같은 작업 메모를 지면에 노출.
- 지어낸 수치·인용·인물·기관. 심의도서에 없는 값은 붉은 더미(`<span class="dummy">[00]</span>`, `[0,000]명`, `11.[00]` 등 실제 자릿수 형태).
- 따옴표 붙인 가짜 인용문. 시민 발언 자리는 `.quote-slot`(회색 라벨: "응답자 A · 2차 · 위치 인지 관련")로 둔다.
- 결과 방향을 미리 단정하지 않는다. 결과형 문장은 완성하되 방향어·수치는 붉은 더미로: 예) "2차의 위치 설명 정답률은 <span class=dummy>[00]%</span>로 1차보다 <span class=dummy>[00]%p [높았다]</span>."
- 같은 7거점 한 줄씩 나열 지면을 반복하지 않는다(7거점 총괄은 장마다 최대 1회).
- 도식 체계(3S·3생활권·STEP 여러 종) 남발 금지. 분류는 4개 분야 하나, 판정은 '가봉' 3분류(상설=잘 맞았다 `.judge.keep` / 수정=고쳐 맞춘다 `.judge.fix` / 중지=다음 실험의 조건 `.judge.next`) 하나로 통일.

## 3. 문체
- 헤드라인(`.hl`)은 그 쪽의 결론 문장, 2줄 이내, 핵심어를 `<em>`(청록). 예: "일곱 거점 모두 사전조사·1차·2차를 <em>같은 요일·같은 시간대</em>에 맞춰 진행하였다"
- `.lede`는 1~2문장 근거. 본문 문장은 짧은 사실문. 주어는 사업·시민·거점·실험.
- 캡션은 "2줄 결론 + 자료 출처" 형식. 출처 표기는 `.foot-src`에 "자료: 인천광역시(2026), 인천 창의디자인 사회실험 사업 심의자료" 식으로만.

## 4. 지면 문법 (Ⅰ장과 동일)
- A4 세로 210×297mm, 한 `<section class="page even|odd">`가 한 쪽. 짝수=왼쪽, 홀수=오른쪽. 펼침면은 짝수-홀수 쌍. **간지는 항상 홀수 쪽.**
- 본문 쪽: `.nav`(현재 장 `.on`) → `.hd`(`.sec` 절번호 칩 `Ⅱ-01` + 절명, `.hl`, 선택 `.lede`) → `.body`(top은 헤더 높이에 맞춰 52~78mm) → `.pno`(두 자리/세 자리 쪽번호) → 필요 시 `.foot-src`.
- nav 문구(고정): `<span>들어가기</span><span>Ⅰ 묻다</span><span>Ⅱ 찾다</span><span>Ⅲ 설계하다</span><span>Ⅳ 실험하다</span><span>Ⅴ 검증하다</span><span>Ⅵ 남기다</span>` (부록 쪽은 nav 없이 써도 됨)
- 간지: `<section class="page odd divider"><div class="horizon"></div><div class="num">Ⅱ</div><div class="kick">찾다</div><div class="ttl">조사와<br>시민참여</div><div class="q">질문 한 줄</div><ol><li>절명<span>쪽</span></li>…</ol></section>` (part1_앞부분.html p5 참고)
- 색: 청록 #1597BE 주조, 남색 #153A5E, 노랑 #F5D33B(결론), 분야색 안전 #2C5DA8 / 포용 #1F9E83 / 매력 #E39A2D / 편의 #8466C6 (CSS 변수 `--f-safe` 등). 빨강은 더미 전용.
- **글과 도식의 비중 (사용자 지시, 최우선)**: 다이어그램·인포그래픽만으로 지면을 채우지 않는다. 보고서는 읽히는 글이 있어야 한다. 한 쪽 안에서 서술과 도식을 자연스럽게 섞고, 쪽마다 비중을 다르게 가져간다.
  - **서술형 쪽**(장·절의 첫 쪽, 기획 배경·변천, 해석·소결, 판단 근거): 본문 서술 3~6문단(쪽당 약 700~1,200자)이 주가 되고, 도식은 작게(사진 1~2컷, 작은 수치 박스, 인용 슬롯, 마진 노트) 보조한다. 2단 본문 + 사이드 컬럼, 리드 문단 + 본문 + 풀쿼트 같은 편집 레이아웃을 쓴다.
  - **혼합형 쪽**(대부분): 도식 1개 + 그 도식을 읽어 주는 본문 2~3문단(약 400~700자)과 2줄 결론 캡션.
  - **도식형 쪽**(총괄 지도, 일정, 매트릭스, 결과 차트): 도식이 주가 되되 해설 문장 1~2문단(약 200~400자)은 반드시 둔다.

  - 본문 서체: 8.4~9pt, 행간 1.7~1.8, 문단 사이 간격, 단 폭 80mm 안팎(2단) 또는 120mm 이하(1단+사이드). 본문은 완료형 사실문으로, 무엇을 했고 무엇을 보았고 왜 그렇게 판단했는지를 구체적으로 쓴다(심의도서의 사실·수치·장소·주체를 근거로). 메타 문장 금지 규칙은 그대로다.
