# 통합 조사설계와 현장 운영안

2026.09.07 작성 · 원 조사표를 실행 가능한 관찰·설문 규칙으로 보완한 제안안

## 1. 공통 운영 기준
조사는 대상지·회차·날짜·관찰창을 기본 단위로 관리한다. 시작 전에 조사범위와 시계를 맞추고 짧은 예비 관찰로 같은 행동을 같은 방식으로 기록하는지 확인한다. 표본 간격과 중지 기준은 결과를 보기 전에 정한다.

원자료에는 공통으로 대상지, 사전·1차·2차, 일자, 시작·종료시각, 구역, 조사자, 날씨, 특이사항, 설치 버전을 기록한다. 운영자의 설명·경품·청소·행사·단속·운항 변화처럼 이용에 영향을 주는 개입도 시간과 함께 남긴다. 참가자의 연락처는 운영용 파일로 분리하고 분석에는 익명 번호를 사용한다.

관찰창은 동일한 길이를 원칙으로 하되 실제 종료시각을 기록한다. 중간 중단·결측이 있으면 유효 관찰시간만 집계한다. 분모가 0이면 비율을 0%로 표시하지 않고 ‘산출 불가’로 표기한다. 조사하지 않은 항목은 빈값 또는 NA로 두며 관찰했지만 발생하지 않은 0과 구분한다.

관찰 단위는 사람·통행·행동·집단·물품·세션 중 하나로 명확히 한다. 같은 사람이 반복 방문하는 것을 구분하지 못하면 ‘고유 이용자’라고 쓰지 않는다. 한 사람의 여러 행태는 복수 코딩하되 합계가 전체 사람 수를 넘을 수 있음을 설명한다.

## 2. 지표별 공통 정의
| 항목 | 정의 | 해석 시 주의 |
| --- | --- | --- |
| 인지율 | 대상 정보를 보았거나 식별한 유효 응답 비율 | 주시·클릭과 동일하지 않음 |
| 내용 식별률 | 공통 확인 문항에서 내용을 올바르게 식별한 비율 | 추측 가능성과 모르겠다 응답을 함께 표시 |
| 참여행동률 | 사전 정의한 행동이 확인된 관찰 건수/유효 관찰 건수 | 단순 통과와 구분 |
| 체류시간 | 동일 방문의 입장·퇴장이 연결되는 종료-시작시간 | 경계 표본·추적 누락을 분리 |
| 5점 만족 문항 | 1 매우 낮음~5 매우 높음 | 분포·중앙값·4~5점 비율과 응답 수 표시 |
| 재참여 의향 | 종료 설문에서 다시 참여하고 싶은 정도 | 실제 재참여와 분리 |
| 실제 재참여 | 익명 연결 가능한 1차 참여자의 2차 출석 | 연결 동의·누락을 표시 |
| 웹 이용 | 시험 접속을 제외한 익명 세션과 사건 기록 | 세션 수를 고유 사람 수로 단정하지 않음 |

통계는 기술통계·비율 차이(%p)·중앙값과 분포를 먼저 제시한다. 충분한 표본과 설계 조건이 있을 때만 적절한 검정을 보조로 사용한다. 동일인 이분형 응답과 독립 집단 비율, 순서형 척도를 구분한다. 단일 거점·소수 일자의 비교에 유의확률만으로 효과를 확정하지 않는다.

## 3. 약산초 조사안
사전 준비: 후보 시설의 번호·사진·기능·위치·통학 노출을 조사자용 지도에 정리한다. 이미지 크기와 제시 방식, 문항 난이도를 맞춘다. 같은 어린이의 응답을 연결할 수 있는 학교 관리 익명번호를 사용한다.

공통 문항 A1: “이 사진 속 표시를 이번 등하굣길에서 본 적이 있나요?” 보기: 봄 / 못 봄 / 모르겠음 / 이 길로 다니지 않음.

공통 문항 A2: “어디에 있었는지 골라 주세요.” 보기: 실제 지도상의 후보 위치 / 모르겠음. 상세 집 주소는 받지 않는다.

공통 과제 A3: “보호자에게 이곳을 알려준다면 어떻게 말할까요?” 답을 그대로 기록하고 0 설명 불가, 1 표식만 언급, 2 지도에서 특정 가능한 표식+장소 설명으로 코딩한다. 조사자가 정답을 알려준 뒤의 응답은 별도 표시한다.

조사자 기록 A4: 학년, 통학 경로, 해당 구간 노출 여부·통학일 수, 워크숍 참여 여부, 제안의 색·형태·이름·행동 단서, 장소 유형·선택 이유. 결과 비교는 노출이 가능한 응답자와 전체 응답자를 각각 제시한다.

워크숍 결과 양식: 익명번호 / 제안 이름 / 표현 설명 / 후보 장소번호 / 선택 이유 / 선정 여부 / 수정 이유. 선정하지 않은 아이디어도 유형 분석에서 제외하지 않는다.

## 4. 선인재단 조사안
관찰 방향은 상행, 구간은 진입-중간-도착으로 고정한다. 관찰번호는 해당 관찰창에서만 유효하다. 시작·중간·도착을 확실히 연결한 경우만 통과시간을 산출한다.

행동 코드 S1: 통과만 / 그래픽 주시 / 가리키기 / 친구에게 알리기 / 나란히 이동 / 기다림 / 멈춤 / 추월·뜀 / 확인 불가. 복수 선택 가능. 웃음·미소, 휴대전화 보기 등은 관찰 사실로만 추가 기록한다.

설문 S2: “오늘 이 길을 오르는 동안 재미있었나요?” 1 전혀 재미없음~5 매우 재미있음.

설문 S3: “오늘 이 길을 오르는 것은 얼마나 힘들었나요?” 1 전혀 힘들지 않음~5 매우 힘듦.

설문 S4: “다음에도 이런 표시가 있는 길을 이용하고 싶나요?” 1 전혀 그렇지 않음~5 매우 그러함. 사전에는 길의 재이용 특성을 묻더라도 설치된 표식에 대한 문항으로 전후 비교하지 않는다.

추가 질문: “어떤 표시가 기억에 남나요?” 한 문장. 표정만으로 흥미·불만족·재참여를 추정하지 않는다. 시간 단축과 속도 경쟁은 목표로 삼지 않는다.

## 5. 송도 조사안
신청 F1: 익명 참여번호 / 신청 회차 / 혼자·지인 동반 / 참여 목적 / 평소 교류 기회 / 선택 언어 / 선택 학교·국적 범주. 연락처는 운영용으로 별도 관리한다.

현장 F2: 출석 / 활동 시작 / 종료 / 스테이션 입·퇴장 / 이용 구간 / 걷기·달리기·휴식·대화·요소 사용 / 운영자 개입. 관찰로 지인 관계·국적을 판정하지 않는다.

종료 F3: “오늘 처음 만난 참여자와 인사하거나 함께 활동했나요?” 예 / 아니오 / 모르겠음. “그 사람은 이 행사에 오기 전부터 알던 사람인가요?” 예 / 아니오 / 응답 원치 않음. 두 문항의 모순 응답은 검토 표시한다.

종료 F4: “코스와 휴식공간이 다른 참여자와 어울리는 데 도움이 되었나요?” 1~5점. 2차에는 “추가된 안내·활동 요소 중 무엇이 도움이 되었나요?”를 복수 선택으로 추가한다. 운영자 문의 응대와 참가자 간 교류는 구분한다.

종료 F5: “다음 회차에도 참여하고 싶나요?” 1~5점. 실제 재참여는 동일 익명번호의 2차 출석으로 확인한다. 1차에서 이미 만난 관계는 재참여자의 기존 관계로 표시한다.

종료 F6: “활동 뒤 주변 카페·식당·가게를 이용했거나 이용할 계획이 있나요?” 실제 이용 / 계획 있음 / 없음 / 모르겠음. 계획과 실제 이용을 분리한다. 점포 쿠폰 집계는 사전 동의한 점포의 익명 건수만 사용한다.

## 6. 차이나타운 조사안
외부 임시 안내판을 주 비교 단위로 정한다. 같은 정보·언어·판면 외곽·위치·시간대·모집 방식을 유지한다. QR 화면의 위치 정보는 에티켓 확인 여부와 무관하게 접근 가능하게 한다.

공통 C1: “방금 이 구간에서 화장실 관련 안내를 보셨나요?” 예 / 아니오 / 모르겠음. QR을 실제 열었는지는 별도 질문으로 받는다.

공통 C2: “어떤 안내였는지 골라 주세요.” 정답 이미지 / 대조 이미지 / 모르겠음. 이미지 순서를 번갈아 제공한다. 안내 미인지자에게 이미지를 보여준 뒤의 반응은 비보조 인지와 분리한다.

공통 C3: 실제 안내한 에티켓 하나의 의미 또는 약도에 표시한 이용 가능한 시설을 묻는 공통 선택문항. 장소 목록이 확정되면 현장 내용에 맞춰 정확한 문항·정답을 고정한다. 국적별 문화 지식이나 상식을 묻지 않는다.

공통 C4: “필요한 정보를 찾기 쉬웠나요?”, “안내 표현이 부담스럽지 않았나요?” 각각 1~5점. 경험하지 않음 별도 선택. 개선 의견은 한 문장으로 받는다.

선택 C5: 같은 내용의 권유형·금지형 예시를 조사 종료 시 제시하고 선호와 이유를 묻는다. 매체 비교의 주 결과와 분리한다.

웹 사건: page_open / map_open / etiquette_open / etiquette_confirm / feedback_positive / feedback_negative / load_error. 기록 필드: 익명세션·지점·회차·발생시각·사건·시험접속 여부. 위치권한과 개인 연락처를 요구하지 않는다. 세션 중복 제거·유효시간창·비활성 탭 처리 기준은 구현 단계에 고정한다.

첫 화면 세션 중 위치를 연 비율과 에티켓을 연 비율을 각각 계산한다. 미응답을 무관심으로 재분류하지 않는다. 1차 설문 인지 인원과 2차 웹 조회를 같은 모집단이라고 가정하지 않는다.

## 7. 굴포천 조사안
구역 G0: 전시 면 / 전시 좌석 / 반대편 좌석 / 휴식 대여 / 활동 / 통과 동선. 최종 명칭·번호는 실측도와 같게 한다. 조사 전·후 동일 시야가 확보되는지 카메라·수기 관찰을 점검한다.

관찰 G1: 임시 방문번호 / 구역 / 입장·퇴장 / 경계 표본 / 3초 이상 멈춤 / 착석 / 감상 / 만짐 / 대화 / 촬영 / 휴식 / 운동·놀이 / 방해·충돌. 행태는 복수 기록한다.

대여 G2: 물품번호 / 품목 / 대여·반납시각 / 실제 사용 확인 / 반납·미반납 / 손상 / 청소시간. 반납률의 분모는 실제 대여 건수다. 대여시간과 실제 운동시간을 동일하게 보지 않는다.

공통 G3: “현재 이 공간은 머물고 싶을 만큼 매력적인가요?”, “현재 공간 이용에 만족하나요?”, “다음에 다시 이용하고 싶나요?” 각각 1~5점.

사전 G4: “이곳에 작가 전시가 생기는 것에 얼마나 기대하나요?” 별도 문항. 사후 만족의 전후 변화량으로 쓰지 않는다.

사후 G5: “작품과 휴식·활동 공간이 잘 어울리나요?”, “다른 활동 때문에 감상이나 휴식이 방해되었나요?” 1~5점. 다른 교량 하부 이용 의향은 보조 문항으로 분리한다.

## 8. 로데오거리 조사안
구역 R0: 부스 예정/설치 구역, 기존 흡연 지점, 인접 보행·점포 출입, 꽁초 계수 범위를 지도에 고정한다. 사전·1차·2차에서 경계가 달라지면 원인과 도면 버전을 남긴다.

행동 R1: 사건번호 / 시작·종료 / 흡연 위치 / 방향 확인시각 / 내부·외부·혼합 / 꽁초 처리 위치 / 처리 확인 가능 여부 / 사인 주시·방향 전환·유입 / 보행 방해. 사람의 신원은 추적하지 않는다.

환경 R2: 관찰 시작 전 바닥 꽁초 / 시작 청소 여부 / 새 꽁초 수 / 수거부 회수 수 / 중간 청소시각·회수량 / 기타 쓰레기 / 바람 방향 / 단속·행사. 바닥 수와 처리행동 수를 합산하지 않는다.

설문 R3: “이 공간을 어떻게 알고 오셨나요?” 사인 / 원래 앎 / 주변 사람 / 지나가다 / 기타. “이용하기 불편했던 점이 있나요?” 한 문장. 사전 벤치 주변 이용에 동일한 부스 질문을 억지로 적용하지 않는다.

올바른 꽁초 처리율은 끝까지 처리 장소가 확인된 사건만 분모로 계산한다. 안쪽 방향 비율도 방향 관찰이 가능한 구역 내 사건을 분모로 삼는다. 실제 간접흡연 변화는 공기질·노출 조사 없이 확정하지 않는다.

## 9. 연안여객터미널 조사안
시점 관찰 T1: 시각 / 1층 일반 대기 인원 / 2층 일반 휴식 인원 / 사용 가능한 좌석 수 / 지정 짐 구역 내 물품 / 경계 물품 / 구역 밖 물품 / 통로 방해. 30분 간격으로 기록한다. 전용공간·직원·단순 이동은 주 비교에서 구분한다.

이용 사건 T2: 임시번호 / 휴식 시작·종료 / 자리 유형 / 경계 표본 / 목적 확인 가능 여부. 시점별 인원 합계와 개별 이용 사건을 같은 숫자로 합치지 않는다.

## 12. 보고값 작성 규칙
결과 문장은 ‘조사 기간·대상·분모 → 관찰값 → 변화 → 제한 → 후속 조치’ 순서로 쓴다. 예시 숫자를 채운 결과표를 미리 만들지 않는다. 빈 결과표는 원자료 입력용임을 표시한다.

좋은 결과뿐 아니라 관찰 누락, 비참여, 안내를 이해하지 못한 이유, 반납 실패, 보행 방해, 지연·결항을 기록한다. 2차에서 조건을 수정했다면 수정 전후를 분리하고 해당 설계 변경의 효과로 범위를 한정한다.

고정시설 후보 판단은 지표 개선·이용 부담·관리 지속성·기관 협의·비용을 함께 검토한다. 후속 사업의 최종 결정은 관할 기관의 절차와 실제 조사 결과에 따른다.
